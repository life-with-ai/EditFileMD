# EditFileMD

`EditFileMD` — локальный portable-редактор Markdown и обычного текста для Windows. Приложение объединяет дерево папок, вкладки, оформленное чтение Markdown и редактирование в одном рабочем окне.

## Скачать

Версия `1.9.0` доступна в разделе [GitHub Releases](https://github.com/life-with-ai/EditFileMD/releases/latest).

Файл portable-версии:

`EditFileMD-1.9.0-windows-x64-portable.zip`

Файл с расширением `.sha256` предназначен для проверки целостности загруженного архива.

## Основные возможности

- открытие отдельных Markdown- и TXT-файлов и нескольких корневых папок;
- безопасное открытие и редактирование HTML, CSS, JavaScript, TypeScript, JSON, XML, YAML, SVG, Python и распространённых конфигурационных файлов как исходного текста;
- дерево файлов, вкладки, закрепление вкладок и режим одной вкладки;
- устойчивое обновление дерева после внешних изменений и отдельное обозначение недоступных корневых проектов;
- показ в дереве обычных файлов любых расширений и файлов без расширения без чтения или запуска неподдерживаемого содержимого;
- отдельная настройка показа скрытых файлов и папок;
- чтение и редактирование Markdown, обычного текста и поддерживаемых исходных форматов без исполнения содержимого;
- безопасный просмотр PNG, JPEG, GIF, WebP и BMP в read-only вкладке;
- GFM-таблицы, task lists, локальные изображения и подсветка кода в Markdown;
- режимы чтения, редактирования и разделённого просмотра;
- стандартное меню `Файл`, `Правка`, `Вид` и `Справка` с едиными командами и сочетаниями клавиш;
- единая панель поиска в чтении и редактировании и замена текста в редактируемых документах;
- экспорт активного поддерживаемого текстового документа в PDF через системное окно сохранения Windows;
- сохранение, сохранение с переходом к чтению, отмена правок и автосохранение;
- контроль внешнего изменения файла и опциональное автоматическое перечитывание без потери несохранённого текста;
- поиск, светлая и тёмная темы, русский и английский интерфейс;
- независимые целочисленные размеры, системные шрифты и отступы текста и кода для редактирования и чтения;
- отдельное оформление номеров строк и активной строки редактора;
- варианты представления Markdown-таблиц с нативным автоматическим распределением ширины, встроенного кода и цитат;
- варианты линий Markdown-заголовков и представления выделенного текста;
- локально встроенные Inter и Cascadia Code для стабильной типографики на поддерживаемых Windows;
- тонкая и средняя толщина полос прокрутки;
- изменение порядка корневых проектов с сохранением выбранной последовательности;
- общий сброс настроек с подтверждением и выбор режима открытия новых редактируемых документов;
- автоматическое определение поддерживаемой кодировки и ручное повторное открытие активного документа в выбранной кодировке;
- явное преобразование активного документа в выбранную кодировку, LF или CRLF с блокировкой записи непредставимых символов;
- изоляция недоступных сетевых проектов без остановки локальных проектов и автоматическое восстановление после возвращения пути;
- восстановление открытых документов и состояния рабочей области;
- руководство пользователя и компактный режим дерева проектов;
- поддержка UTF-8, UTF-8 BOM, UTF-16 LE/BE BOM, Windows-1251, Windows-1252, CP866, KOI8-R, KOI8-U, ISO-8859-5, LF и CRLF;
- локальная работа без аккаунта, телеметрии, сервера и облачной синхронизации.

## Системные требования

- Windows x64;
- установленный Microsoft Edge WebView2 Runtime.

Протестированные системы:

- Windows 8.1 x64;
- Windows 10 x64;
- Windows Server 2025 Standard 24H2 x64.

Совместимость с Windows 11 x64 не проверена.

Microsoft Edge WebView2 Runtime часто уже установлен в Windows. Если компонент отсутствует, его следует загрузить с [официальной страницы Microsoft](https://developer.microsoft.com/en-us/microsoft-edge/webview2/#download-section). Runtime не входит в portable ZIP.

## Portable-запуск

1. Скачать ZIP из раздела Releases.
2. При необходимости проверить SHA-256 архива по приложенному checksum-файлу.
3. Полностью распаковать архив в обычную пользовательскую папку с правом записи.
4. Запустить `EditFileMD.exe`.

Установка в Windows не требуется. Настройки и состояние рабочей области хранятся в каталоге `data` рядом с исполняемым файлом. Рабочие документы остаются в папках, выбранных пользователем.

## Безопасность и приватность

Активный HTML в Markdown фильтруется. Неподдерживаемые файлы не читаются и не запускаются внешней программой. Удалённые ресурсы из Markdown-документов не загружаются.

EXE не подписан коммерческим сертификатом подписи кода. При первом запуске Windows SmartScreen может показать предупреждение неизвестного издателя.

Подробные сведения приведены в документах [PRIVACY.md](PRIVACY.md) и [SECURITY.md](SECURITY.md).
