# EditFileMD 1.1.0

Выпуск улучшает ежедневную работу с деревом файлов, уведомлениями и режимом одной вкладки.

## Файлы выпуска

- `EditFileMD-1.1.0-windows-x64-portable.zip` — portable-версия приложения;
- `EditFileMD-1.1.0-windows-x64-portable.zip.sha256` — контрольная сумма SHA-256.

Идентификатор сборки: `efmd-1.1.0-285e8123`.

SHA-256 portable ZIP:

`285E8123098901AC6BD76784B221D529A1A8B949323A40E5832BEF6EB4D0EC3B`

## Изменения

- Свёрнутое дерево файлов сохраняет компактную вертикальную полосу с кнопкой повторного раскрытия.
- Уведомления получили единый нейтральный стиль и семантические состояния для светлой и тёмной тем.
- В режиме одной вкладки выбранный режим чтения, редактирования или разделённого просмотра сохраняется при последовательном открытии файлов.

## Системные требования

- Windows x64;
- Microsoft Edge WebView2 Runtime.

Протестированные системы:

- Windows 8.1 x64;
- Windows 10 x64;
- Windows Server 2025 Standard 24H2 x64.

Microsoft Edge WebView2 Runtime доступен на [официальной странице Microsoft](https://developer.microsoft.com/en-us/microsoft-edge/webview2/#download-section).

## Запуск portable-версии

1. Скачать portable ZIP и файл контрольной суммы.
2. Проверить SHA-256 архива.
3. Распаковать архив в обычную пользовательскую папку с правом записи.
4. Запустить `EditFileMD.exe`.

## Известные ограничения

- EXE не подписан коммерческим сертификатом подписи кода; Windows SmartScreen может показать предупреждение неизвестного издателя.
- Microsoft Edge WebView2 Runtime не включён в portable ZIP.
- Совместимость с Windows 11 x64 не проверена.

## Локальность данных

EditFileMD работает локально и не использует аккаунт, телеметрию или облачную синхронизацию.
