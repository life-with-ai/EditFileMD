# EditFileMD 1.3.0

Выпуск расширяет настройки интерфейса, редактирования и чтения Markdown-документов.

## Файлы выпуска

- `EditFileMD-1.3.0-windows-x64-portable.zip` — portable-версия приложения;
- `EditFileMD-1.3.0-windows-x64-portable.zip.sha256` — контрольная сумма SHA-256.

Идентификатор сборки: `efmd-1.3.0-c4c7106b`.

SHA-256 portable ZIP:

`C4C7106B5F429FC63FF024E8EF546DFC3DC99DC789BD35C3B8C21B9957D688FA`

## Изменения

- Окно настроек разделено на вкладки `Основные`, `Интерфейс`, `Редактирование` и `Чтение`.
- Для редактора и чтения добавлены независимые шрифты Windows, межстрочные интервалы, цвета фона, текста и элементов Markdown.
- Markdown-подсветка поддерживает единый цвет и отдельную палитру заголовков, ссылок, полужирного текста, курсива, кода, цитат и маркеров списков.
- Верхняя панель, панель проектов и вкладок и дерево проектов получили независимые настраиваемые цветовые блоки.
- Добавлен выбор поведения при запуске: предыдущая сессия или пустая область проектов.
- Улучшены прокрутка, разделители, геометрия дерева, поля выбора и автоматически скрываемая верхняя панель.
- Исправлено циклическое восстановление устаревших вкладок после некорректного состояния сессии.

## Системные требования

- Windows x64;
- Microsoft Edge WebView2 Runtime.

Протестированные системы:

- Windows 8.1 x64;
- Windows 10 x64;
- Windows Server 2025 Standard 24H2 x64.

Microsoft Edge WebView2 Runtime доступен на [официальной странице Microsoft](https://developer.microsoft.com/en-us/microsoft-edge/webview2/#download-section).

## Запуск portable-версии

1. Скачать portable ZIP и файл контрольной суммы.
2. Проверить SHA-256 архива.
3. Распаковать архив в обычную пользовательскую папку с правом записи.
4. Запустить `EditFileMD.exe`.

## Известные ограничения

- EXE не подписан коммерческим сертификатом подписи кода; Windows SmartScreen может показать предупреждение неизвестного издателя.
- Microsoft Edge WebView2 Runtime не включён в portable ZIP.
- Совместимость с Windows 11 x64 не проверена.

## Локальность данных

EditFileMD работает локально и не использует аккаунт, телеметрию или облачную синхронизацию.
