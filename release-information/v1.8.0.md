# EditFileMD 1.8.0

## Файлы выпуска

- `EditFileMD-1.8.0-windows-x64-portable.zip` — portable-версия приложения;
- `EditFileMD-1.8.0-windows-x64-portable.zip.sha256` — контрольная сумма SHA-256.

Идентификатор сборки: `efmd-1.8.0-df69aae5`.

SHA-256 portable ZIP:

`DF69AAE59509A09D32531782E541E72072B36423362BFF30BD7AAAA58D80CB3D`

## Изменения

- Добавлено чтение и сохранение десяти утверждённых Unicode- и legacy-кодировок.
- Добавлены автоматическое определение и ручное повторное открытие активного документа в выбранной кодировке.
- Активный документ можно явно преобразовать в выбранную кодировку, LF или CRLF.
- Открытие файла не изменяет его байты; непредставимые символы блокируют запись без повреждения исходного файла.
- Добавлены отдельная вкладка настроек кодировок и окончаний строк, пассивные индикаторы формата и расширенное руководство.
- Ошибки файловых операций локализованы на русский и английский языки через единый структурированный контракт.
- Недоступный сетевой ресурс больше не блокирует интерфейс, не останавливает локальные проекты и автоматически восстанавливается после возвращения пути.

## Системные требования

- Windows x64;
- Microsoft Edge WebView2 Runtime.

Portable smoke выполнен на Windows 10 x64. Этот же неизменённый ZIP дополнительно прошёл практическую пользовательскую проверку и принят как финальный локальный вариант.

Microsoft Edge WebView2 Runtime доступен на [официальной странице Microsoft](https://developer.microsoft.com/en-us/microsoft-edge/webview2/#download-section).

## Запуск portable-версии

1. Скачать portable ZIP и файл контрольной суммы.
2. Проверить SHA-256 архива.
3. Распаковать архив в обычную пользовательскую папку с правом записи.
4. Запустить `EditFileMD.exe`.

## Известные ограничения

- EXE не подписан коммерческим сертификатом подписи кода; Windows SmartScreen может показать предупреждение неизвестного издателя.
- Microsoft Edge WebView2 Runtime не включён в portable ZIP.
- Совместимость с Windows 11 x64 не проверена.

## Локальность данных

EditFileMD работает локально и не использует аккаунт, телеметрию или облачную синхронизацию.
