# EditFileMD 1.4.0

Версия готовится как локальный release candidate и ещё не опубликована на GitHub.

## Изменения

- Дерево проектов показывает обычные файлы любых расширений и файлы без расширения.
- Добавлена сохраняемая настройка показа скрытых файлов и папок, включая `.git`.
- Неподдерживаемый файл можно выбрать без чтения содержимого, создания вкладки или запуска внешней программы.
- PNG, JPEG, GIF, WebP и BMP открываются в отдельной read-only вкладке с масштабированием и прокруткой.
- Переполненная панель вкладок получила стрелки навигации и меню закрытия всех либо только незакреплённых вкладок.
- Добавлены руководство пользователя и компактный режим дерева проектов.
- Разделённый режим получил быструю пропорциональную синхронизацию прокрутки и устойчивое восстановление раздельных позиций.
- Добавлено опциональное автоматическое перечитывание внешних изменений с защитой несохранённого текста.
- Обновлены значки панели проектов и индикатор несохранённых изменений во вкладке.

## Безопасность и локальность

- Содержимое файлов не читается при построении дерева.
- Неподдерживаемые файлы не запускаются внешней программой.
- Image-viewer проверяет тип, размер и геометрию изображения до передачи данных декодеру.
- SVG, PDF, RAW и другие активные либо сложные форматы не включены.
- Новые сетевые запросы, телеметрия и внешние runtime-зависимости не добавлены.

## Системные требования

- Windows x64;
- Microsoft Edge WebView2 Runtime.

Microsoft Edge WebView2 Runtime доступен на [официальной странице Microsoft](https://developer.microsoft.com/en-us/microsoft-edge/webview2/#download-section).

## Финальная проверка

Имя portable ZIP, SHA-256 и результаты финального smoke будут зафиксированы после сборки единого release candidate.
