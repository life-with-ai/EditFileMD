# EditFileMD 1.0.0

Первый публичный выпуск локального portable-редактора Markdown- и текстовых файлов для Windows.

## Файлы выпуска

- `EditFileMD-1.0.0-windows-x64-portable.zip` — portable-версия приложения;
- `EditFileMD-1.0.0-windows-x64-portable.zip.sha256` — контрольная сумма SHA-256.

Идентификатор сборки: `efmd-1.0.0-152711d2`.

## Основные возможности

- чтение и редактирование `.md`, `.markdown` и `.txt`;
- несколько папок и файлов в одной рабочей области;
- дерево документов и вкладки;
- режимы чтения, редактирования и разделённого просмотра;
- GFM-таблицы, task lists, локальные изображения и подсветка кода;
- поиск, светлая и тёмная темы, русский и английский интерфейс;
- контроль внешних изменений, автосохранение и восстановление рабочей области;
- локальная работа без аккаунта, телеметрии и облачной синхронизации.

## Системные требования

- Windows x64;
- Microsoft Edge WebView2 Runtime.

Протестированные системы:

- Windows 8.1 x64;
- Windows 10 x64;
- Windows Server 2025 Standard 24H2 x64.

Совместимость с Windows 11 x64 не проверена.

## Запуск

1. Скачать portable ZIP и файл контрольной суммы.
2. Проверить SHA-256 архива.
3. Распаковать архив в обычную пользовательскую папку с правом записи.
4. Запустить `EditFileMD.exe`.

Microsoft Edge WebView2 Runtime доступен на [официальной странице Microsoft](https://developer.microsoft.com/en-us/microsoft-edge/webview2/#download-section).

## Известные ограничения

- EXE не подписан коммерческим сертификатом подписи кода; Windows SmartScreen может показать предупреждение неизвестного издателя.
- Microsoft Edge WebView2 Runtime не включён в portable ZIP.
- Совместимость с Windows 11 x64 не проверена.
