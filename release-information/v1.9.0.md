# EditFileMD 1.9.0

## Файлы выпуска

- `EditFileMD-1.9.0-windows-x64-portable.zip` — portable-версия приложения;
- `EditFileMD-1.9.0-windows-x64-portable.zip.sha256` — контрольная сумма SHA-256.

Идентификатор сборки: `efmd-1.9.0-de690768`.

SHA-256 portable ZIP:

`DE690768DC58CC1171F895B93CDEB642FE9FB291347EBB2A6316773AC04ED948`

## Изменения

- Добавлен экспорт активного поддерживаемого текстового документа в PDF через системное окно сохранения Windows.
- Markdown экспортируется в оформленном виде, а обычный текст и поддерживаемые исходные форматы — как текстовый листинг без исполнения содержимого.
- Экспорт учитывает текущее содержимое редактора, включая несохранённые изменения, и не изменяет исходный файл.
- Команды приложения распределены между меню `Файл`, `Правка`, `Вид` и `Справка`.
- Добавлена единая панель поиска для чтения и редактирования; замена доступна для редактируемого исходного текста.
- Меню, сочетания клавиш и элементы интерфейса используют единые команды с учётом активного документа и доступности действия.

## Системные требования

- Windows x64;
- Microsoft Edge WebView2 Runtime.

Неизменённый portable ZIP проверен на Windows 8.1 x64, Windows 10 x64 и Windows Server 2025 Standard 24H2 x64. Совместимость с Windows 11 x64 не проверена.

Microsoft Edge WebView2 Runtime доступен на [официальной странице Microsoft](https://developer.microsoft.com/en-us/microsoft-edge/webview2/#download-section).

## Запуск portable-версии

1. Скачать portable ZIP и файл контрольной суммы.
2. Проверить SHA-256 архива.
3. Распаковать архив в обычную пользовательскую папку с правом записи.
4. Запустить `EditFileMD.exe`.

## Известные ограничения

- EXE не подписан коммерческим сертификатом подписи кода; Windows SmartScreen может показать предупреждение неизвестного издателя.
- Microsoft Edge WebView2 Runtime не включён в portable ZIP.
- Совместимость с Windows 11 x64 не проверена.

## Локальность данных

EditFileMD работает локально и не использует аккаунт, телеметрию или облачную синхронизацию.
