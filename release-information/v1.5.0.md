# EditFileMD 1.5.0

## Изменения

- Добавлено безопасное открытие, редактирование и read-only чтение HTML, CSS, JavaScript, TypeScript, JSON, XML, YAML, SVG и Python как исходного текста.
- Подключены распространённые конфигурационные расширения и точные имена файлов, включая `.gitignore`, `.editorconfig`, `.env`, `Dockerfile` и `Pipfile`.
- Исходные форматы получили языковую подсветку CodeMirror; Markdown сохранил собственный rendered reader и пользовательскую палитру.
- Дерево и вкладки используют отдельные локальные иконки типов файлов из единого реестра форматов.
- Руководство пользователя содержит актуальный перечень поддерживаемых форматов и точные границы каждого режима.
- Соседние корневые проекты показаны компактно без искусственной разделительной линии.

## Безопасность и локальность

- HTML, JavaScript, SVG, Python и конфигурационные файлы не исполняются.
- Visual HTML-preview и visual SVG-preview в эту версию не входят.
- Новые форматы используют существующие ограничения локальных путей, кодировок, атомарного сохранения и контроля внешних изменений.
- Новые сетевые запросы, телеметрия, внешний API и отдельный runtime не добавлены.

## Системные требования

- Windows x64;
- Microsoft Edge WebView2 Runtime.

Microsoft Edge WebView2 Runtime доступен на [официальной странице Microsoft](https://developer.microsoft.com/en-us/microsoft-edge/webview2/#download-section).
