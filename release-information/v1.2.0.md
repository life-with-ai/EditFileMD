# EditFileMD 1.2.0

Выпуск улучшает работу с закреплёнными вкладками, режимом одной вкладки и синхронизацией разделённого просмотра.

## Файлы выпуска

- `EditFileMD-1.2.0-windows-x64-portable.zip` — portable-версия приложения;
- `EditFileMD-1.2.0-windows-x64-portable.zip.sha256` — контрольная сумма SHA-256.

Идентификатор сборки: `efmd-1.2.0-aa7b45bc`.

SHA-256 portable ZIP:

`AA7B45BC69AB93668CD428DCB035D54A3F0BF26013F30DCE2F481315ADB8E301`

## Изменения

- Вкладку можно закрепить отдельной кнопкой. Закреплённые вкладки располагаются слева и сохраняются между запусками.
- В режиме одной вкладки закреплённые документы не заменяются; рядом используется одна обычная переиспользуемая вкладка.
- В настройках разделённого режима можно включить двустороннюю синхронизацию прокрутки редактора и просмотра.
- Обновлены логотип окна «О программе» и Windows-иконки приложения.

## Системные требования

- Windows x64;
- Microsoft Edge WebView2 Runtime.

Протестированные системы:

- Windows 8.1 x64;
- Windows 10 x64;
- Windows Server 2025 Standard 24H2 x64.

Microsoft Edge WebView2 Runtime доступен на [официальной странице Microsoft](https://developer.microsoft.com/en-us/microsoft-edge/webview2/#download-section).

## Запуск portable-версии

1. Скачать portable ZIP и файл контрольной суммы.
2. Проверить SHA-256 архива.
3. Распаковать архив в обычную пользовательскую папку с правом записи.
4. Запустить `EditFileMD.exe`.

## Известные ограничения

- EXE не подписан коммерческим сертификатом подписи кода; Windows SmartScreen может показать предупреждение неизвестного издателя.
- Microsoft Edge WebView2 Runtime не включён в portable ZIP.
- Совместимость с Windows 11 x64 не проверена.

## Локальность данных

EditFileMD работает локально и не использует аккаунт, телеметрию или облачную синхронизацию.
