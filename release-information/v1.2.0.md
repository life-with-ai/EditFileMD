# EditFileMD 1.2.0

Версия подготовлена как локальный release candidate и ещё не опубликована на GitHub.

## Изменения

- Вкладку можно закрепить отдельной кнопкой. Закреплённые вкладки располагаются слева и сохраняются между запусками.
- В режиме одной вкладки закреплённые документы не заменяются; рядом используется одна обычная переиспользуемая вкладка.
- В настройках разделённого режима можно включить двустороннюю синхронизацию прокрутки редактора и просмотра.
- Обновлены логотип окна «О программе» и Windows-иконки приложения.

## Системные требования

- Windows x64;
- Microsoft Edge WebView2 Runtime.

Microsoft Edge WebView2 Runtime доступен на [официальной странице Microsoft](https://developer.microsoft.com/en-us/microsoft-edge/webview2/#download-section).
