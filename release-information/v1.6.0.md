# EditFileMD 1.6.0

## Файлы выпуска

- `EditFileMD-1.6.0-windows-x64-portable.zip` — portable-версия приложения;
- `EditFileMD-1.6.0-windows-x64-portable.zip.sha256` — контрольная сумма SHA-256.

Идентификатор сборки: `efmd-1.6.0-f438ee88`.

SHA-256 portable ZIP:

`F438EE8808173114DB7C043DBDCD60C19C228B231488FAA65F7CA16981677CDC`

## Изменения

- Добавлены независимые целочисленные размеры и системные шрифты текста и кода для редактирования и чтения.
- Добавлены настраиваемые горизонтальные и вертикальные отступы текста и кода в обеих рабочих областях.
- Оформление номеров строк и активной строки редактора получило независимые цветовые параметры.
- Добавлены тонкая и средняя толщина полос прокрутки для дерева проектов и рабочих областей.
- Добавлены варианты представления Markdown-таблиц, встроенного кода и цитат.
- Корневые проекты можно перемещать выше и ниже с сохранением выбранного порядка.
- Смешанные LF/CRLF больше не блокируют редактирование и нормализуются только при обычном сохранении.
- Разделитель split-режима больше не увеличивает ширину рабочей области.
- Обновлены руководство, папочные иконки, логотип окна «О программе» и системная иконка приложения.

## Системные требования

- Windows x64;
- Microsoft Edge WebView2 Runtime.

Протестированные системы:

- Windows 8.1 x64;
- Windows 10 x64;
- Windows Server 2025 Standard 24H2 x64.

Microsoft Edge WebView2 Runtime доступен на [официальной странице Microsoft](https://developer.microsoft.com/en-us/microsoft-edge/webview2/#download-section).

## Запуск portable-версии

1. Скачать portable ZIP и файл контрольной суммы.
2. Проверить SHA-256 архива.
3. Распаковать архив в обычную пользовательскую папку с правом записи.
4. Запустить `EditFileMD.exe`.

## Известные ограничения

- EXE не подписан коммерческим сертификатом подписи кода; Windows SmartScreen может показать предупреждение неизвестного издателя.
- Microsoft Edge WebView2 Runtime не включён в portable ZIP.
- Совместимость с Windows 11 x64 не проверена.

## Локальность данных

EditFileMD работает локально и не использует аккаунт, телеметрию или облачную синхронизацию.
