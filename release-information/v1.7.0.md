# EditFileMD 1.7.0

## Файлы выпуска

- `EditFileMD-1.7.0-windows-x64-portable.zip` — portable-версия приложения;
- `EditFileMD-1.7.0-windows-x64-portable.zip.sha256` — контрольная сумма SHA-256.

Идентификатор сборки: `efmd-1.7.0-ccbcca7b`.

SHA-256 portable ZIP:

`CCBCCA7BFCEAC6744445DE8C0F2EEDBCDF32BD4BC22D837C592010C8497E1927`

## Изменения

- Добавлены общий сброс настроек с подтверждением и выбор режима открытия новых редактируемых документов.
- Дерево проектов устойчиво обновляется после внешних переименований и отдельно обозначает недоступный корневой проект.
- Настройки цветов и заливки иконок дерева разделены по типам элементов.
- Добавлены варианты линий Markdown-заголовков и два представления выделенного текста.
- Все варианты Markdown-таблиц используют нативное автоматическое распределение ширины без ручных минимумов колонок.
- Синхронизация прокрутки разделённого режима учитывает актуальные размеры областей и точно сводит начало и конец документа.
- В portable-пакет встроены Inter и Cascadia Code вместе с применимыми лицензиями.
- Заводские настройки чтения используют размер `14 px` для текста и кода, поэлементную Markdown-подсветку и выделенный текст без рамки.

## Системные требования

- Windows x64;
- Microsoft Edge WebView2 Runtime.

Portable smoke выполнен на Windows 10 x64. Этот же ZIP дополнительно прошёл практическую пользовательскую проверку.

Microsoft Edge WebView2 Runtime доступен на [официальной странице Microsoft](https://developer.microsoft.com/en-us/microsoft-edge/webview2/#download-section).

## Запуск portable-версии

1. Скачать portable ZIP и файл контрольной суммы.
2. Проверить SHA-256 архива.
3. Распаковать архив в обычную пользовательскую папку с правом записи.
4. Запустить `EditFileMD.exe`.

## Известные ограничения

- EXE не подписан коммерческим сертификатом подписи кода; Windows SmartScreen может показать предупреждение неизвестного издателя.
- Microsoft Edge WebView2 Runtime не включён в portable ZIP.
- Совместимость с Windows 11 x64 не проверена.

## Локальность данных

EditFileMD работает локально и не использует аккаунт, телеметрию или облачную синхронизацию.
